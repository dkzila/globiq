## Key Decisions

1. **One canonical Source per normalized URL** (§11 applied to evidence) — two items citing the same URL share the record; the dedup key is the normalized URL (lowercase host, fragment dropped, trailing slash stripped).
2. **Sources are platform-level; scope lives on the LINK** — the record has no country dimension (a UN report can back any market); `content:manage` on the item's unit-country governs attach/detach/claim-edit, enforced server-side with denial audits (§20).
3. **Links are live provenance metadata, audited** — public reads expose current citations immediately (adding evidence is trust-increasing; every change audited). The §36 revision-immutability discipline governs content, not citation metadata; the deliberate tradeoff is documented.
4. **UNRELIABLE sources are refused on new links but never deleted** — trust revocation is a mark; existing citations remain as preserved history (§36 migration-safe philosophy).
5. **aiAssisted: working copy on the item, frozen on the revision** — mirrors the working-copy/live-revision pattern; every published revision carries its own provenance flag; the existing state machine (no publish-from-DRAFT) IS the §26 review gate.
6. **Verification is its own small state machine** (SOURCE_VERIFICATION_TRANSITIONS) — the shared-vocabulary pattern (KNOWLEDGE_/CONTENT_ transitions) extended to evidence trust.
7. **source:manage as its own permission** — platform-level for COUNTRY_ADMIN (no object narrowing); P2-S4's WRITER grants can add source access without content rights.
8. **Read/manage split on citations** — COUNTRY_ADMIN views global items' citations read-only (content parity), matching getAdminContentItems semantics.
