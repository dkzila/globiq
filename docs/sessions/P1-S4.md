## What Was Delivered

### 1. Schema (Prisma → Supabase)

- `Topic` — canonical node: immutable `slug` (URL-stable, kebab-case, globally unique), `canonicalName`, `description`, `type` (DOMAIN/BRANCH/TOPIC), `status` (ACTIVE/INACTIVE/RETIRED — RETIRED = soft-delete), `scope` (GLOBAL/COUNTRY) + `countryId` (explicit, never inferred — §14), self-relation `parent`/`children`, `orderIndex`.
- `TopicLabel` — one localised name/description per language (`@@unique([topicId, languageId])`).
- `TopicAlias` — alternate search terms, optional language (`@@unique([topicId, value])`).
- Back-relations on `Country`/`Language`; indexes on (parentId, orderIndex), status, (scope, countryId).

### 2. Taxonomy Module (`src/modules/taxonomy/`)

- `cache.ts` — snapshot cache (60s TTL, write-invalidated): topics with labels+aliases, languages, countries — public reads cost zero DB round-trips after warm-up (§29 pattern).
- `service.ts` — domain logic:
  - **Public reads:** `getPublicTree` (country/language-aware; only ACTIVE nodes with a fully-ACTIVE ancestor chain; label fallback chain requested-language → country-default → canonicalName), `getPublicTopic` (path, labels, aliases, children; hidden statuses → 404), `searchTopics` (case-insensitive across canonicalName, slug, any-language labels, aliases; `matchedOn` provenance).
  - **Scoped RBAC (§38):** `topicActorFromAuth` (home country resolved via cached snapshot); ADMIN = full control incl. root domains; COUNTRY_ADMIN = own-country extensions only (own country implied when omitted on create), global nodes read-only, roots forbidden.
  - **Structural invariants (§13/§36):** DOMAIN only at root and only GLOBAL; only DOMAIN may be root; slug/scope/type immutable after create; cross-country subtree containment forbidden (`CROSS_COUNTRY_SCOPE`); move = cycle check + reparent rules; INACTIVE↔ACTIVE free but restore under inactive parent blocked; retirement is explicit (DELETE), leaf-first, and RETIRED nodes are read-only archives.
  - **Labels/aliases:** replace-semantics PUT, ACTIVE-language validation, duplicate detection (per-language for labels, case-insensitive for aliases).
- `validation.ts` — zod schemas (strict slug grammar; COUNTRY-requires-country enforced in the service where the actor context allows a country admin's home country to be implied); `types.ts` — public DTOs incl. per-node `permissions` the UI renders from.

## Known Dev-Mode Observation (not a product bug)

Next.js dev compiles each route with its own module registry, so the in-memory snapshot cache is **not shared across routes** in dev: a write (POST/PATCH/DELETE) invalidates its own route's cache but a different route (e.g. public tree vs. admin detail) may serve stale data for up to the 60s TTL. Observed twice during testing (INACTIVE node visible on detail route for <60s; freshly-created node 404 on detail route for <60s); both self-healed after TTL and all invariants were verified end-to-end after expiry. In a production build all routes share one module instance, so invalidation is global. No code change required — documented for future sessions.

## Key Decisions

1. **Immutable slug/scope/type after creation** (§36): renames touch canonicalName/labels only; structural reclassification = new node. Keeps URLs and mappings stable for P3 (SyllabusNode → topic refs).
2. **Deletion is always soft (RETIRED)** — leaf-first enforced; RETIRED nodes are read-only archives; recovery is an admin DB operation (documented), not a UI button.
3. **Country applicability modelled as scope+countryId on the node** (not a join table): GLOBAL nodes render everywhere; COUNTRY nodes only in their market; cross-country subtree containment is rejected at write time.
4. **COUNTRY_ADMIN country is implied when omitted** on create (their home country) — full ADMIN must always specify it explicitly.
5. **One label per language** (§13); public label fallback: requested → country default → canonicalName (`labelLanguage: 'canonical'` exposes the fallback in the UI).
6. **Exams never enter the taxonomy** (§13) — enforced by design; the exam→topic mapping surface arrives in P3 via SyllabusNode.
