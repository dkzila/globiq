## What Was Delivered

### 1. Country & Locale Module (`src/modules/country-locale/`)

- `url.ts` — **canonical URL builder** (§16): the single source of URL truth. Default market (India) omits its slug; each country's default language omits its segment; all URLs built from country + language + object identity, never from raw user input.
- `cache.ts` — in-memory snapshot cache (60s TTL, write-invalidated; §29 evolution path): countries + configured languages + language table in one immutable snapshot.
- `service.ts` — domain logic:
  - **Public reads:** country list/detail (INACTIVE hidden), per-country languages with canonical home URLs (§35 — never a global language list publicly).
  - **Locale resolution:** `resolveLocaleContext({country?, language?})` and `resolveFromPath(path)` — the exact algorithm the P4 middleware will use: country slug → language (only if configured for that country) → remaining content path. Lenient for redundant segments (`/en/`, `/in/`, `/uk/en/`) with `isCanonical: false` + `canonicalUrl` as the redirect target.
  - **URL-space safety (§16):** reserved route words can never be country slugs; the default market's root-level language codes can never collide with country slugs (`URL_COLLISION` guard).
  - **Admin configuration:** create/update country, replace a country's language set, create/update language — with invariants: default root market immutable (slug/status frozen), default language must stay in every country's set, language codes immutable, deactivation blocked while configured/in use.
- `validation.ts` — zod schemas for all admin writes; `types.ts` — public DTOs.
- Second full module proving the §28 pattern (thin routes, explicit interface).

### 2. APIs (§37)

| Endpoint | Method | Auth | Purpose |
|---|---|---|---|
| `/api/countries` | GET | — | Public countries + languages + canonical URLs |
| `/api/countries` | POST | ADMIN | Create country (ISO, slug, name, timezone, status, default language) |
| `/api/countries/[iso]` | GET | — | Country detail (ISO or slug) |
| `/api/countries/[iso]` | PATCH | ADMIN | Update (default market frozen) |
| `/api/countries/[iso]/languages` | PUT | ADMIN | Replace the country's language set |
| `/api/languages` | GET | ADMIN | Platform language table (config view) |
| `/api/languages` | POST | ADMIN | Create language |
| `/api/languages/[code]` | PATCH | ADMIN | Update (code immutable, in-use guard) |
| `/api/locale/resolve` | GET | — | Resolve `?path=` or `?country=&language=` → context + canonical URL + remaining path |

- New shared guard: `src/lib/api/guard.ts` — `requireAuth` / `requireRole` (platform roles; scoped permissions land in P1-S5).
- New shared zod helper: `src/lib/validation.ts` (`fieldErrors`) — identity-access re-exports it, no duplication.
- Error codes added: `COUNTRY_NOT_FOUND`, `COUNTRY_INACTIVE`, `LANGUAGE_NOT_FOUND`, `LANGUAGE_NOT_CONFIGURED`, `LANGUAGE_INACTIVE`, `ISO_TAKEN`, `SLUG_TAKEN`, `CODE_TAKEN`, `URL_COLLISION`, `DEFAULT_COUNTRY_IMMUTABLE`, `DEFAULT_LANGUAGE_REQUIRED`, `DEFAULT_LANGUAGE_NOT_CONFIGURED`, `LANGUAGE_IN_USE`.
